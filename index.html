Grupo 8

Una identidad común

Interacción sin JavaScript

Una página que responde a quien la explora.

¿Qué partes puedo modificar? +

Textos, nombres, colores, tarjetas, enlaces, títulos y secciones. La estructura está preparada para que puedas personalizarla rápidamente.

¿Tiene interacciones? +

Sí. Incluye scroll suave, efectos hover, tarjetas con profundidad, menú móvil, acordeones, animaciones ambientales y botones funcionales.

¿Usa JavaScript? +

No. Toda la experiencia funciona únicamente con HTML y CSS.
